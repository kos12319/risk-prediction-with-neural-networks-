# Architecture Decision Records (ADRs) — Moved

ADRs have moved to `docs/architecture/ADRs/`.

Why move?
- Keep all architecture documentation (overview, journal, ADRs) under a single `docs/architecture/` namespace.

Where to look now:
- New home: `docs/architecture/ADRs/`
- Journal: `docs/architecture/journal/`
- Canon (generated): `docs/architecture/PLATFORM_SPEC.md` (build with `make docs-canon`)

This directory remains as a legacy index to avoid breaking old references.
